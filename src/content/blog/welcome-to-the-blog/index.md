A post is just a markdown (.md) file. The bit at the top between the `---` lines is called _frontmatter_: it holds the title, date, category, tags and cover image. Everything below it is the post itself, written in Markdown.

## Markdown

You write plain text. A blank line starts a new paragraph. Then:

- `## Words` makes a heading. Different numbers of `#`s make different levels of heading. Fewer `#`s = bigger heading.
- `*words*` makes _italics_, `**words**` makes **bold**
- `[link text](https://example.com)` makes a [link](https://example.com)
- Lines starting with `-` make a list like this one
- You can also make numbered lists, blockquotes, code blocks, and more. [This is a good reference](https://www.markdownguide.org/cheat-sheet/).

## Pictures

Put an image file in the same folder as your post, then reference it by name like this:

```markdown
![Alt text for the image](./kim-kitsuragi.jpeg)
```

The site automatically optimises images when it's published, so photos straight from a phone are fine — they'll be resized and compressed for you.
