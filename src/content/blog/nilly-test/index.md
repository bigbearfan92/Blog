- `## Words` makes a heading. Different numbers of `#`s make different levels of heading. Fewer `#`s = bigger heading.

## Pictures

Put an image file in the same folder as your post, then reference it by name like this:

```markdown
![Alt text for the image](./kim-kitsuragi.jpeg)
```

The site automatically optimises images when it's published, so photos straight from a phone are fine — they'll be resized and compressed for you.
